LiveWall

A free, open-source Mac menu bar app that plays a looping video behind your desktop icons.

Download for Mac View source on GitHub

Free. macOS 14+. Apple Silicon. 1.4 MB.

What it does

Pick a video, and LiveWall renders it one layer below your desktop icons, so it sits behind everything on screen and loops without a seam. I built this because every video-wallpaper app I found was paid, Windows-only, or ate my battery.

  • Plays any MP4, MOV, or M4V video, or sets a PNG, JPEG, or HEIC image
  • Gallery window with drag-and-drop import
  • Fills every display from a single hardware decode
  • Lives in the menu bar only — no Dock icon
  • Launches at login if you want it to
  • Remembers your wallpaper across restarts

Battery

A wallpaper should never be the reason your fans spin up, so playback pauses whenever it can't be seen or shouldn't be running: when the screen locks, when displays sleep, when the wallpaper is fully covered by windows, when Low Power Mode is on, or — optionally — whenever you're on battery.

While playing a 4K HEVC loop on Apple Silicon, LiveWall uses roughly 1–3% CPU. Paused, it's effectively zero. Static images go through macOS's own wallpaper API, so nothing runs at all. And it never keeps your display awake.

Install

  1. Download the DMG from the latest release.
  2. Drag LiveWall into Applications.
  3. The first time, right-click the app and choose Open. LiveWall is ad-hoc signed but not notarized (notarization needs a paid developer account), so Gatekeeper blocks a normal double-click on first launch.

If you'd rather clear the quarantine flag from the terminal:

xattr -dr com.apple.quarantine /Applications/LiveWall.app

Build it yourself

The whole app is plain Swift with zero third-party dependencies, MIT licensed. If you have Xcode installed:

git clone https://github.com/lyndon050516/LiveWall.git
cd LiveWall
./scripts/build-app.sh

That produces a ready-to-run LiveWall.app. If something breaks, open an issue and I'll take a look.
